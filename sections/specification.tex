\subsection{Introduction}

% Write one sentence or phrase to introduce it. Then add some text to
% shortly explain it; 1-2 sentences could be enough if you phrase it nicely,
% but can be longer, up to 3-4 sentences.
Human computer interaction is integral for bridging between humans and computer as user interface. As part of user interface, due to processing times and cycles, there are often delays that might happen that would cause end-to-end latency. The effect is particularly noticeable and important in real-time applications such as video games. High latency can cause disruptions, delaying users' actions and therefore leads to poor user experience and performance.
\\
Shneiderman et al. \cite{Shneiderman2016-ln} recommended an end-to-end latency of 50 to 150 ms for simple tasks such as typing, since small amounts of latency can be perceived by users in certain situations. Ng et al. \cite{Ng2012-ns} found that latency below 20 ms can be noticed on touch screens. Even though there is vast amount of research done on the influence of latency on users task, especially typing, there have been no user studies investigating visual prosthetics latencies into the user's visual feed compared to normal vision to our knowledge. Therefore, Our team wants to measure how introducing visual feed could affect typing performace in different delay times.

\subsection{Research Question}

% one for the quantitative task, one for the user experience task
% Phrase your questions. If necessary, further explain them.
The goal of this research is to explore how visual feed could impact users' typing performance with different latencies. Specifically, we want to ask these questions:
\begin{itemize}
	\item \textbf{RQ1 :} How does visual latency affect typing performance?
	\item \textbf{RQ2 :} Is the effect of latencies impacting users linearly or exponentially?
\end{itemize}
In order to answer this RQs, we will do user studies using typing task to analyze how different kind of latencies impacts user performance and experience.

\subsection{Hypotheses}

Our first assumption for the results of this is increased latency reduces typing performance. We also posit that there would be a point after which the delay is so high that it plateaus, typing becomes extremely slow to the point it feels impossible to finish the typing task. We also hypothesize that the relation between latency and typing performance is exponential. There could also be a point where there is steeper drop of performance than before.
